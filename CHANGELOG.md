# Changelog

## 0.1.0

Initial public release.

- Typed, composable KeyPaths with stable structural identity.
- CaseKeyPaths for sealed Kotlin hierarchies, including composition and payload factories.
- `@Pathable` KSP catalogs for source-owned types.
- Kotlin/JVM, Android, and iOS Kotlin/Native support for the core APIs.
- Optional JVM reflection factories for conventional data-class cases.

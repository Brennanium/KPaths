# API reference

The generated Kotlin reference is published alongside these guides. Use its module navigation to
start with:

- `kpaths-core` for KeyPath and CaseKeyPath types,
  factories, composition, operations, identity, and standard-library paths.
- `kpaths-annotations` for `@Pathable`.

For an explanation of *when* to choose an overload, use the narrative guides first: [KeyPaths](../key-paths.md),
[CaseKeyPaths](../case-paths.md), and [generated catalogs](../generation.md). Run `./gradlew docsBuild`
before publishing or serving the site so that this reference is regenerated from the current KDoc.
